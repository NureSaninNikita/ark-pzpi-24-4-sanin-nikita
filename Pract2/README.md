# Приклади рефакторингу Game для ПЗ2

Вихідний проєкт: https://github.com/NureSaninNikita/Game
Коміт: f7dd16d737ac6f7e45f90a5df6574dd81bbcef0d

before/ містить чотири оригінальні модулі. after/ містить їх змінені версії та новий position.py.
Методи: Extract Method, Replace Temp with Query, Introduce Parameter Object.

Для запуску перевірок потрібен Python 3.8 або новіший:
python verify_refactoring.py

Pygame для перевірок не потрібен. Перевіряються 3 сценарії створення ворогів,
7 варіантів графічних викликів і 2500 сценаріїв видимості.
Скрипт читає реальні модулі before/ і after/ та ізольовано виконує потрібні фрагменти.
Повна гра не запускається.

Для інтеграції в окремій повній копії Game замініть чотири модулі файлами з after/
та додайте position.py поряд із physics.py і mage.py. Потрібні решта файлів
і залежності вихідного проєкту. Після інтеграції перевірте гру вручну.

Завантажте вміст папки Pract2 у Pract2/ репозиторію практичних робіт.
Перед остаточним здаванням додайте у звіт прямі GitHub-посилання на after/ файли.
